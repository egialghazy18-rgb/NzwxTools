# Nzwx Tools

Futuristic Tools Suite - Flutter App

## Features
- Liquid Glass UI (Glassmorphism)
- Auth Page (Login/Register)
- Bottom Nav: Beranda, Tools, Bug WA, Setting
- Tools Integration (via Termux)

## Build APK
Otomatis via GitHub Actions — lihat tab **Actions**.

## Download
Setelah build selesai, buka:
`Actions` → workflow terakhir → `Artifacts` → `nzwx-release`
